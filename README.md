# Predicting Secondary Psychopathy from Childhood Trauma
### ML Pipeline — Bachelor Thesis in Cognitive Science & AI

---

## Overview

This project investigates whether self-reported childhood trauma can predict secondary psychopathy scores in adulthood using machine learning. The pipeline covers the full workflow from raw survey data through scale scoring, class balancing, model training, and explainability analysis.

**Target variable:** Secondary psychopathy (LSRP), binarised as Low (≤22) vs High+ (>22)  
**Input features:** Five CTQ-SF subscales — Emotional Abuse, Physical Abuse, Sexual Abuse, Emotional Neglect, Physical Neglect

## Pipeline

| Part | Description |
|------|-------------|
| 0 | Imports |
| 1 | Data loading & cleaning (participant exclusions, type conversion) |
| 2 | Scale scoring — LSRP secondary psychopathy & CTQ-SF subscales |
| 3 | Clinical severity encodings (sample characterisation only, not used as features) |
| 4 | Range validation & save cleaned dataset |
| 5 | Feature selection (5 CTQ-SF subscales) |
| 6 | Target distribution & binary binning (Low vs High+) |
| 7 | Stratified 80/20 train/test split |
| 8 | Feature scaling (StandardScaler, fit on train only) |
| 9 | Random oversampling to address class imbalance |
| 10 | Regression pipeline  |
| 11 | Classification pipeline with GridSearchCV hyperparameter tuning |
| 12 | Test set evaluation (accuracy, balanced accuracy, sensitivity, specificity, PPV, NPV, F1, AUC) |
| 13 | Confusion matrices |
| 14 | ROC curves |
| 15 | Feature importance (coefficients / permutation importance) |
| 16 | SHAP explainability (TreeExplainer, LinearExplainer, KernelExplainer) |

## Models

**Regression (not reported):** Linear Regression, Elastic Net, Random Forest, KNN

**Classification (reported):** Logistic Regression, Random Forest, KNN, SVM  
All classifiers use `class_weight='balanced'` and are tuned with 5-fold stratified cross-validation optimising balanced accuracy.

---

## Instruments

**LSRP** (Levenson Self-Report Psychopathy Scale) — Secondary psychopathy subscale, 10 items (range 10–40). Items 20 and 24 are reverse-scored.

**CTQ-SF** (Childhood Trauma Questionnaire – Short Form) — 28 items across five subscales. Ten protective items are reverse-scored prior to subscale computation.

| Subscale | Items | Range |
|---|---|---|
| Emotional Abuse | 5 | 5–25 |
| Physical Abuse | 5 | 5–25 |
| Sexual Abuse | 5 | 5–25 |
| Emotional Neglect | 5 | 5–25 |
| Physical Neglect | 8 | 8–40 |

Clinical severity cutoffs follow Bernstein & Fink (1998).

## Data

The raw data file `df_wide.csv` is not included in this repository due to participant confidentiality. Participants with out-of-range item responses were excluded.

To reproduce the results, place your own `df_wide.csv` (with the expected column structure) in the project root before running the pipeline.
